# Gmail (mail.google.com)

- **Sign-in:** Ana's Gmail is signed in in her own Chrome (Claude in Chrome).
- **Search:** open a search URL to read one message without browsing the
  inbox. For example
  `https://mail.google.com/mail/u/0/#search/to%3A<address>+in%3Aanywhere`.
  Open only the messages the task names.
- **Opening a result:** click the subject text in the row, away from the
  hover "Unsubscribe" button.
- **Helpers:** a helper declined to open Gmail on a relayed request, so the
  main agent opens it, where Ana's yes was given.
