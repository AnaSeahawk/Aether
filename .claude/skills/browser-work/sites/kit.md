# Kit (app.kit.com)

- **Sign-in:** Ana is signed in in her own Chrome (Claude in Chrome).
- **Forms:** `/forms`, then the "Forms" tab, then "New form".
- **Sending settings:** `/account_settings/email`. "Domains" is in the
  Settings menu.
- **API check:** the public V3 API key is in gopass at `kit.com/v3-api-key`.
  Use it to check forms and tags after a helper's changes. Pipe it in; never
  print it.
- **Form editor:** `/forms/designers/<id>/edit?iframe=false`. Its only save
  button is "Save & Publish", which publishes the form, so ask Ana first.
- **Welcome email:** the form's Settings has no "Incentive" section; it is
  called "Confirmation email". "Send confirmation email" is on by default,
  which makes it double opt-in. "After confirming" offers Download with a
  file upload, and Kit renames the file it is given.

- **Recommendations (Creator Network):** `/creator-network`, then Settings,
  then Recommendations. "Edit" picks which forms show other creators'
  newsletters; as of 2026-11-21 none do, and "Enable by default" is off.
- **Helpers:** they decline or are refused on save, publish and settings
  clicks. The main agent makes those clicks, where Ana's yes was given.
